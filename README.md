# 🌧️ Rainfall Data Analysis with Python

This project explores and visualizes rainfall data using Python's powerful data analysis and visualization libraries. It provides insights into rainfall trends over time and across months, using interactive plots and summary statistics.

## 📚 Libraries Used

- **Pandas** – for data loading, cleaning, and transformation.
- **Matplotlib** – for basic plotting (bar charts, line plots).
- **Seaborn (sns)** – for enhanced statistical visualizations.

## 📊 Features

- ✅ Cleaned the dataset by removing unnecessary columns (e.g., `YEAR`, `ANNUAL RAINFALL`).
- ✅ Transformed monthly columns into a single column for better plotting.
- ✅ Visualized rainfall patterns using:
  - **Bar plots** for month-wise rainfall comparison.
  - **Line plots** to show trends over time.
- ✅ Used `sns.lineplot()` for clean, smooth visualizations.
- ✅ Added titles, axis labels, and styling for clarity.
